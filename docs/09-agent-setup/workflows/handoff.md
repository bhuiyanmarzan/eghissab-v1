# Handoff

Read root AGENTS.md and update docs/00-ai-context/next-session.md with:

- Last completed task and its actual status.
- Active task, owner, precise write scope and remaining steps.
- Next eligible task ID and dependency evidence; blocked tasks are not silently skipped.
- Relevant paths and exact first action for a new agent with no conversation history.
- Outstanding business/technical approvals and permission blockers.
- Actual commands/results, NOT RUN checks and known security risks.
- Concurrent work/integration dependencies and who owns shared files.

Cross-check current-status and backlog. The recipient starts with [start-session](start-session.md); handoff is not a lock or automatic permission to broaden scope.
