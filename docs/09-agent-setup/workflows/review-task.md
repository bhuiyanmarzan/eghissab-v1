# Review Task

1. Read root AGENTS.md, task scope, acceptance criteria and related source/design.
2. Review diff without writing unless separately assigned remediation scope.
3. Check dependency direction, transaction boundaries, input/identity trust, row policies, grants, errors and sensitive data.
4. Distinguish source-confirmed defects from suspected runtime risks. Never claim tests ran from file existence.
5. Record findings by impact with paths, required changes and actual evidence. Do not approve business decisions on the user's behalf.
6. Return review to the write owner; keep independent review changes out of their owned files.
