# ADR-002: Store role

- Recorded: 2026-10-22; original approval date UNKNOWN.
- Status: ACCEPTED business decision, explicitly approved per user-supplied initialization instructions.
- Context: shared identity across organizations, stores and consumer relationships.
- Decision: One active role per user per store.
- Alternative: Multiple simultaneous roles (not selected).
- Consequences: Role replacement must atomically retain one effective assignment.
- Related modules: store.
- Related rule: BR-002 in [business rules](../../01-product/business-rules.md).
- Superseded by: none.
- Implementation: not implemented in this repository; this acceptance does not approve a particular schema or API design.
