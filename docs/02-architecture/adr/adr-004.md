# ADR-004: Store entitlement

- Recorded: 2026-10-22; original approval date UNKNOWN.
- Status: ACCEPTED business decision, explicitly approved per user-supplied initialization instructions.
- Context: shared identity across organizations, stores and consumer relationships.
- Decision: Valid paid or trial entitlement permits store creation.
- Alternative: Paid-only creation (not selected).
- Consequences: Quota and entitlement checks must be atomic with creation; grace-period details unresolved.
- Related modules: billing, store.
- Related rule: BR-004 in [business rules](../../01-product/business-rules.md).
- Superseded by: none.
