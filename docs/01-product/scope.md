# Scope

## Target product scope
Three portals; shared identity; organization ownership and membership; billing entitlement and quotas; store RBAC; employees, customers, products, inventory and invoices; verified consumer links, invoice decisions and expenses; platform audits. React web is present only as a starter; Expo mobile is planned. These are target requirements, not a commitment that all are MVP-ready.

## Current initialization scope
Documentation and agent coordination only. Preserve all application code and migrations; no runtime tests, migrations, infrastructure installation or deployment. Stage protected agent files and report the blocker.

## Not approved / deferred
Microservice extraction, new major infrastructure, payment provider selection, unrestricted support bypass, retroactive consumer invoice access and new financial/tax rules. Listing prototype's place in the product is UNKNOWN. Reconcile proposed tasks and acceptance criteria before implementation.
